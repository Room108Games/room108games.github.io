# Room108 Website & Wicked West

Official website for **Room108** game studio and showcase for **Wicked West**.

- **Studio**: Room108
- **Creator & Developer**: Burstyn Santillo
- **Featured Game**: Wicked West (Godot 4)

---

## Tech Stack & Features

- **Frontend**: Semantic HTML5, Modular CSS3, Vanilla JavaScript (ES6+)
- **Typography**: Mogra (Headings) & Chicle (Body)
- **Palette**: Dark & Light mode support (`#DDE9CE`, `#8CC63F`, `#0B9444`, `#0a140d`)
- **Physics**: Planetary floating sprite simulation with velocity, continuous rotation, and drag/fling momentum
- **Audio**: Custom Web Audio API retro synthesizer with sound effects and soundtrack controls
- **Zero Build Tools**: Works directly in any browser with zero compilation or node dependencies

---

## Local Preview

Serve the website directory locally using Python:

```powershell
python -m http.server 8000
```

Then visit:
- Studio Home: `http://localhost:8000/index.html`
- Wicked West: `http://localhost:8000/wicked-west.html`
